Connect to GitHub

Publish needs an access key from GitHub. You make it once. It is saved only in this browser.

  1. Open github.com/settings/personal-access-tokens/new while signed in as .
  2. Token name: anything, for example Site editor. Pick an expiration you are comfortable with.
  3. Repository access: choose Only select repositories and pick .
  4. Permissions: open Repository permissions and set Contents to Read and write.
  5. Click Generate token, copy it, and paste it here.
